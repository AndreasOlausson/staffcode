# Changelog

## Unreleased

## 0.0.2 - 2026-10-01

- Rename Staffcode to Stackoda, including the Python package and command-line
  entry point. The `.staff` source format remains unchanged.

- Clarify that 100,000 execution steps is the minimum portable profile, not a
  limit imposed by the Stackoda language.
- Add an optional Rockstar 2 composer that generates executable Stackoda
  scores from text.

## 0.0.1 - 2026-09-28

- Publish the first reference implementation and language specification.
- Include arithmetic, stack operations, input/output and Unicode characters.
- Include persistent accidentals, key signatures and barline restoration.
- Include repeats, nested conditionals, volta endings and D.S./Coda replay.
- Add runnable examples, an instruction inspector and conformance tests.
